# 📌 Overview

DataPilot AI is a comprehensive data analytics platform designed to simplify the process of analyzing datasets. The application allows users to upload CSV or Excel files and instantly generate statistical summaries, interactive dashboards, dynamic visualizations, AI-generated insights, and downloadable reports—all through an intuitive web interface.

The project demonstrates practical implementation of data analytics concepts using Python and modern visualization libraries, making it suitable for business analysis, educational purposes, and portfolio showcasing.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Pratik2684/DataPilot-AI-Analytics-Platform.git
```

Go to the project directory

```bash
cd DataPilot-AI-Analytics-Platform
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
